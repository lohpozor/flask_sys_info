# Carv Sys — заметки для Claude

Учебный проект: системный дашборд на Flask, который показывает состояние **этого** Windows-ПК
(i7-9700, RTX 3060 Ti). Репозиторий: github.com/lohpozor/flask_sys_info, ветка `main`.

## Формат работы

- Пользователь учится бэкенду с нуля и хочет научиться разрабатывать с помощью ИИ-агента. Общение на русском.
- Код пишет Claude, а не пользователь. Изменения делать маленькими шагами, объяснять, что сделано и зачем,
  и показывать, как проверить результат (запуск, вывод, `git diff`).
- Не задавать вопросов по темам, которые ещё не объяснялись.
- Коммитит и пушит пользователь сам, если не попросит иначе.

## Структура

- `app.py` — Flask-приложение: `/` (страница), `/health`, подключает blueprint из `api.py`.
- `api.py` — blueprint с префиксом `/api`: `/api/info` (статичное, запрашивается один раз), `/api/metrics` (опрашивается).
- `metrics.py` — сбор данных: psutil (CPU, RAM, диск, сеть, uptime, процессы) и nvidia-ml-py (GPU).
- `version.py` — `APP_VERSION`.
- `templates/index.html`, `static/style.css`, `static/dashboard.js` — фронтенд. Стиль — тёмная «автомобильная» панель:
  фон `#14141f`, зелёный акцент, скруглённые панели, точки статуса через `data-status` и CSS-переменную `--status`.
- `start.bat` — запуск через waitress на `127.0.0.1:5002`, сам открывает браузер.

## Принятые решения (не предлагать заново)

- **Без Docker.** Контейнер видит свою изолированную систему или VM WSL, а не хост, поэтому для этого дашборда он бесполезен.
  Docker уместен только позже, для Linux-сервера.
- **Температура CPU на Windows — `N/A`.** Настоящим датчикам нужен драйвер ядра с правами администратора, а встроенная
  ACPI-зона отдаёт фиктивные 27.9 °C. Вариант с LibreHardwareMonitor пользователь отклонил. На Linux температуру читает psutil.
- **waitress, а не gunicorn:** gunicorn не работает на Windows.
- **`.bat` — только ASCII.** Кириллица в UTF-8 ломает разбор команд в cmd.
- `cpu_percent(interval=0.5)` пользователь поставил сам, `REFRESH_MS = 500` тоже. Не менять без спроса.
